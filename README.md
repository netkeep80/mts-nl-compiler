# mts-nl-compiler

Обучаемый компилятор естественно-языковых требований и метатребований на **взвешенной асети дуплетов**.

## Направление

- Предметные знания, грамматические конструкции, отношения и правила представляются **связями**, а не параллельной онтологией классов.
- На первом этапе используется минимальное строковое множество идентификаторов и две таблицы: `(link, begin, end, weight)` и `(link, string)`.
- Числовой `weight` хранится непосредственно в строке связи. Кодирование весов связями отложено.
- ИИ предлагает обучение и проверочные контрпримеры; обычная компиляция должна быть воспроизводимой без обращения к ИИ.
- Исследование не переносит полную онтологию или семантику исполнения принятой МТС v0.15. Адаптер к FORMAL — самостоятельный будущий этап, не источник authority хранилища.

## Минимальное хранилище

`db/schema.sql` определяет **ровно две таблицы**: `links` и `strings`.

`data/links.json` и `data/strings.json` — Git-версионируемые исходные строки соответствующих таблиц. SQLite — **производная локальная проекция**, а не второй редактируемый источник истины. В базе данных нет дополнительных таблиц знаний.

Сейчас данные пусты намеренно: отбор первых конструкций обучения следует после определения идентичности связей и семантики веса.

## Первичная проверка

Требуется Node.js 24+.

```bash
npm test
```

Проверка строит SQLite в памяти из двух исходных массивов, контролирует схему и воспроизводит тестовые строки, включая рекурсивные ссылки и границы числового веса.
