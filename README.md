# mts-nl-compiler

## Наблюдение за тестами — Observatory

**[Открыть Observatory — официальный GitHub Pages](https://netkeep80.github.io/mts-nl-compiler/observatory/)** · [HTML в main](https://github.com/netkeep80/mts-nl-compiler/blob/main/docs/observatory/index.html) · [исходный PR #95](https://github.com/netkeep80/mts-nl-compiler/pull/95).

Панель показывает предсказания фраз B0, найденные Link-сочетания B1, сравнения с n-граммами, отрицательные тесты и историю проверок CI. Интерфейс **опубликован в `main`**, но результаты B0/B1 остаются исследовательскими статическими снимками, а не онлайн-мониторингом или доказательством понимания языка.

Обучаемый компилятор на взвешенной асети дуплетов. Новая **исследовательская** P0-модель — **одна** таблица `links(link_id,from_id,to_id,string,weight,from_uses,to_uses)`. Структурные счётчики — производный кэш, а не частота наблюдений; weight [0,1] либо NULL пока не имеет доказанной вероятностной семантики. База знаний/правил не разделяется на типовые таблицы.

Эксперимент `src/dag.mjs` исследует точное восстановление произвольных Unicode-последовательностей по бинарным DAG и переиспользование пар. «мама»: 3 уникальных пары в левом дереве против 2 при общем `ма`. Меньшее число пар **не доказывает** правильности смысла или максимального MDL-сжатия.

`corpus/pilot.json`: 40 синтетических коротких строк из пяти направлений (русский язык, литература, математика, логика, программирование). **Это не собрание учебников и не размеченный смысловой эталон.** Настоящий корпус должен состоять из проверенных по лицензии материалов; см. [issue #9](https://github.com/netkeep80/mts-nl-compiler/issues/9).

Запуск: Node.js 24+ и `npm test`. Тесты пока проверяют структуру, кэш счётчиков и точное восстановление Unicode; обучения, вывода MP и распознавания смысла в P0 нет.

Roadmap: [#1](https://github.com/netkeep80/mts-nl-compiler/issues/1), [однотабличная миграция #8](https://github.com/netkeep80/mts-nl-compiler/issues/8), [MDL и проверяемая семантика #10](https://github.com/netkeep80/mts-nl-compiler/issues/10), [научные стадии #13](https://github.com/netkeep80/mts-nl-compiler/issues/13). `repo-guard` зафиксирован по exact SHA в advisory, trusted BASE первого bootstrap не установлен; `anet-memory` — только навигация; GitHub — источник истины. Без автоматического merge и без изменений принятой МТС v0.15.
