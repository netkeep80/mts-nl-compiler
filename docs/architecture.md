# Однотабличная взвешенная асеть (P0, candidate)

Предлагается одна таблица links(link_id,from_id,to_id,string,weight,from_uses,to_uses). Идентичность задаёт link_id; одинаковые полюса разных Links допустимы. Атом: оба полюса NULL и строковая подпись, дуплет: оба полюса заданы и подпись необязательна. Вес NULL значит «не определён», 0 — определённое число; диапазон [0,1] — лишь P0 ограничение хранения, а не принятая семантика вероятности. В отличие от исторического P0, в базе нет второй предметной таблицы strings.

Счётчики from_uses/to_uses являются только производным кэшем количества других хранимых дуплетов, ссылающихся на данный link_id в соответствующей полюсной позиции. При link (x,x) обе позиции увеличиваются независимо. Ни наблюдения, ни обучения эти числа не измеряют. Canonical Git data/links.json содержит только пять исходных колонок. Кэши всегда можно пересчитать. SQL-схема — одна предметная таблица, SQLite — производная проекция Git.

## Минимальное исполняемое свидетельство

src/dag.mjs — ограниченный эталон точного декодирования упорядоченных бинарных деревьев с hash-consing. Для «мама»: левая бинаризация 3 уникальных дуплета, сбалансированная с повторным использованием «ма» — 2; обыкновенные развернутые деревья имеют по 3 внутренних вхождения. Для малого n выполняется исчерпывающий перебор структур. Это не универсальный компилятор и не доказательство смысловой правильности сжатия.

## Корпус и критерии

corpus/pilot.json содержит 40 самостоятельно составленных синтетических строк из русского языка, литературы, математики, логики и программирования, включая латиницу, математические формулы и Unicode. Это пока не учебники и не независимый semantic gold; он служит свидетельством восстановления. Приоритет для настоящего корпуса — лицензированные русскоязычные учебники по всем пяти направлениям; отдельно реальные литературные тексты. Проверять индивидуальные лицензии, авторство, издания, версию и SHA. Текст не нужно жёстко делить на слова или «исправлять» до анализа.

Считать отдельно уникальные связи, раскрытые вхождения, стоимость полной сериализации, MDL модель+данные, смысловые ошибки, неизвестные гипотезы, обобщение на heldout. Снижение числа дуплетов не может оправдывать смысловую ошибку или наивную запись всего текста одним атомом. Универсальная реакция Γ, вероятностное обучение и эксперименты с LiNo/link-cli ещё не реализованы и отслеживаются issues #5–#13.
