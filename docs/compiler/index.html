W21 · локальный исследовательский движок

Фраза → дуплеты → Link

Введи любой текст. Компилятор построит бинарную структуру, покажет найденные повторения, Link с левым и правым полюсами, метрики переиспользования и результат точного восстановления Unicode. Никакого словаря и специальных правил для пробелов.

Исходная последовательность

Режим Re-Pair изучает частоты на этом же вводе — это не обучение на независимом корпусе. Числовые ID — временные локальные номера, не постоянные SQLite Link ID.

Результат

Сравнение одной последовательности

Одинаковый ввод и символы для всех режимов. Уникальные пары — структурная мера, не объём SQLite и не MDL.

Найденные правила повторений

Показывается только в режиме Re-Pair. Частоты измеряются на последовательности текущих токенов с проверкой неперекрывающихся замен.

Дуплеты и переиспользование

Каждый Link вида Lᵢ=(Lₐ⟼Lᵦ). Использования учитываются в развёрнутом дереве исходного текста, а не в SQLite.
