# E7 — инкрементальный Link-корень полного исходного текста

## Область действия

Исследовательский структурный источник `src/incremental-source-root-e7.mjs`. Каждый внешний Unicode scalar дополняет один текущий immutable source-root, связываемый в той же пятиколоночной модели Link, что и P0. Это **не** синтаксический/смысловой разбор, нативная Γ, accepted FORMAL, MDL или алгоритм исправления слов. Принятые МТС v0.15 контракты не изменяются.

## Алгоритм

Поток разбивается на правосторонние полные блоки размеров степеней двух. При добавлении одного символа новый одноэлементный блок каскадно объединяется только с равновеликими соседними блоками (binary carry). Ведущий root является левым свёртыванием блоков. Количество новых структурных pair-операций на символ не более порядка `O(log n)`; выбираемое содержимое источника восстанавливается без полного повторного обхода прежних символов.

Каждый атом и ду́плет имеет `a:/p:` ID из SHA-256 canonical JSON содержимого; одинаковые пары совместно используются, но альтернативные физические Link-идентичности в общей МТС остаются допустимыми. Этот **узкий** структурный компилятор работает только с собственными content-derived ID, не декларирует всеобщую канонизацию произвольных связей.

Каждое добавление собирает новые строки в staging Map; бюджет `maxRows` и `maxCodePoints` проверяется **до** публикации текущего root, событий, SHA. Повторный `eventId` с прежним scalar => `REPLAY_NOOP`, противоречивый replay => ошибка. Старые корни можно читать отдельно. Всегда различаются текущие reachable rows и все исторически удержанные строки.

## Оракулы и критерий

Независимый reference строит каждый префикс **заново** из исходных Unicode codepoints, затем создаёт фиксированную power-of-two binary shape через базовый P0 `makeTree/encodeShared` и требует идентичного root SHA. По каждому префиксу также сверяется точное содержимое и исходные UTF-8 байты по SHA-256. Отрицательные тесты: replay ID collision, недопустимый surrogate, слишком много scalar/Links, ошибочная decode budget, нарушение одиночной SQLite предметной таблицы.

Отдельный SQLite replay загружает **только reachable** строки текущего root, повторно восстанавливает исходный текст и проверяет структурные счётчики `from_uses/to_uses`, которые не являются наблюдениями.

## Оставшиеся проверки

- Реальные полные книги/статьи из exact-pinned corpus, время P50/P95, O(log n) фактические touched links, память, selected/retained Link counts.
- E7 selected-root vs E6 optimized content-stable root: сравнивать только decoded UTF-8 равенство и полный бюджет Link, **не** идентичность их topologies.
- Эффективная инкрементальная синхронизация rule-selected старых фрагментов, Context, Γ, provenance и атомарная publication в SQLite — это отдельные этапы.
- Инвариант итогового `tar.zst` продукта с полной arbitrary Link identity базой относится к #44–#46, не доказан этим экспериментом.
