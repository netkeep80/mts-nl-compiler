# Воспроизводимый bootstrap базы Link (первый gate #45)

`src/knowledge-snapshot-v0.mjs` строит **только начальную физическую проекцию** принятой однотабличной модели SQLite `links` из пяти полей Git-источника `data/links.json` и доверенного `db/schema.sql`.

Порядок строк и SQL-вставки нормализован по точному `link_id` без locale; `weight=null` отличается от `weight=0`, повторные ID отвергаются, параллельные связи с разными ID разрешены, циклы сохраняются, dangling endpoints блокируются. Структурные `from_uses/to_uses` пересчитываются и проверяются. `VACUUM INTO` создаёт временный SQLite, который удаляется после получения bytes; весь результат возвращается как `sqlite` и `manifest` с `graph.sha256`, `sqliteSha256`, `schemaSha256` и **единой** `productVersion`.

Сборка дважды в независимых временных каталогах и обратная перестановка строк должны давать идентичные logical SHA и физические bytes SQLite на текущем pinned Node/SQLite toolchain. Это тест релизной инфраструктуры, **не доказательство** межплатформенной побайтовой идентичности или научной корректности знаний.

В текущем baseline `data/links.json` пуст, поэтому источник явно маркируется `BOOTSTRAP_UNTRAINED__NOT_SEMANTICALLY_VERIFIED`. Готовой обученной БД нет. Данные книг и статей не включены, источниковая provenance/лицензии нуждаются в точном `sources.lock` (#45). Никакой публичный release/archive здесь ещё не создаётся.

Следующий gate #46: безопасный детерминированный tar.zst с кодом, этим `knowledge.sqlite`, manifest и digest; затем отдельный cold-readonly consumer и независимая сборка. Для нормативного выпуска потребуется явное одобрение владельца и CI workflow grant.
