# E4 — поздний пересмотр при одном символе

Фальсифицируемая научная постановка: старый текст `ab×6000+cd×6000+c`. До нового наблюдения частоты `ab` и `cd` равны; после единственного нового символа `d` частота `cd` становится на единицу выше, изменяя выбранное обобщённое правило. Источник — одна неизменяемая внешняя последовательность с добавлением одного символа.

Из начала источника выделена старая неизменная view `ab×128`; она используется **только для повторной декодируемой оценки** под двумя моделями правил и НЕ учитывается в частотах как второе внешнее наблюдение. От её конца до нового символа >10000 codepoints. Повторный структурный проход обязан выявить смену выбранного root/дуplet ids этой view, при этом собственные байты probe и всех источников восстановлены точно.

Сравнивать **два разных показателя**: #unique reachable duplets текущей выбранной сети и #unique Links с удержанием старого + нового графа (историческое сохранение может увеличить стоимость). Контроль без обучения `maxRounds=0`: Link root probe должен остаться прежним, хотя появился один новый символ.

**Граница**: повторный полный пересчёт обучающей структурной грамматики, не нативный Γ/MP, не частотное weight semantics, не событийнная agenda; нет гарантии уменьшения общего графа от одного символа. Исходная принятая МТС v0.15 не изменена. E4 это baseline для будущей event-driven Γ.
