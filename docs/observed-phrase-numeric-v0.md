# #68 W3 — обучаемая сегментация частых пар слов в реальные Link

Экспериментальный двухпроходный компилятор, следующий за W2, без SHA-идентификаторов Link и без подмены принятой МТС v0.15.

На первом проходе по неизменённым исходным Unicode-строкам считаются пары слов, разделённые только пробелами или табуляцией. Пунктуация и перевод строки прерывают кандидата. Частота наблюдений и число документов учитываются отдельно, а временные нормализованные ключи пар НЕ являются физическими Link ID.

На втором проходе из точных исходных байтов строятся числовые SQLite AUTOINCREMENT Link, сначала для слов и разделителей, затем для выбранных частых пар word+separator. Выбранные phrase Link являются достижимыми от финального root, а не вспомогательными записями вне графа. Регистр, диакритика, U+FEFF, CRLF и пунктуация должны восстанавливаться без изменения. Условия выбора: ограниченный список наблюдаемых кандидатов и минимум две реальные позиции.

При перекрытии кандидатов алгоритм сначала выбирает более частую пару; при равной частоте — более раннюю исходную позицию. Отвергнутые из-за пересечения позиции не становятся выбранными phrase Links, хотя остаются независимыми исходными статистическими наблюдениями.

Физическая identity целиком принадлежит SQLite и не вычисляется из символов или полюсов. Уникальность полюсной пары не вводится, повторное использование узла является явной настройкой.

Ограничение: это лишь frequency-guided segmentation по биграммам, не доказанная семантика и не условная вероятность натурального языка; МТС weight не меняется. Нельзя оценивать обобщение на обучающих же документах. Следующий строгий gate — A/B/C на полном закреплённом корпусе 60 книг с train/held-out split, physical Link counts, rooted phrase coverage, TOP1000, SQLite bytes, throughput и cold exact replay. Для измерения скорости нужны повторные AB/BA прогоны.

Тесты: наблюдения исходных пар, сохранение границ предложений, выбранный physical phrase Link достижим от root, UTF-8 roundtrip, rollback на SQL ошибке, стабильность числа наблюдений.
