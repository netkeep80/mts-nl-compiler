# E0 — Компиляция реальных книг и статей

Исследовательский запуск по исходным файлам из независимых репозиториев; скрипт **не генерирует и не подменяет тексты**. Шесть файлов: две книги/пьесы Пушкина, эссе Толстого «Две войны», книга Кэрролла «Alice's Adventures in Wonderland» и две документальные статьи MDN о JavaScript.

Манифест `corpus/real-sources-e0.json` содержит версии upstream commit, SHA1 точных Git blobs, размер оригинальных файлов, авторство, лицензию, атрибуцию и ссылки. Runner GitHub Actions делает sparse checkout только нужных файлов, строго по commit SHA. Печатные тексты не добавляются в текущий репозиторий и не включаются в результаты измерений.

Этап E0 выполняет существующий P0 `codePoints → makeTree(balanced) → encodeShared → decodeShared`; проверяет **байтовое** равенство исходной UTF-8 последовательности и восстановленного значения. Отдельно объединяет идентичные дуплеты across documents в одну предметную SQLite таблицу `links`, строит производные индексы `from_id/to_id`, пересчитывает структурные счётчики и декодирует **все** исходные документы после физической загрузки.

Измеряются input bytes, Unicode codepoints, unique atoms, unique pair Links, expanded occurrences, JSON bytes graph including SHA identities, gzip(level6) bytes of original text, time, RSS и total corpus graph. Вывод в лог `E0_DOC` и `E0_CORPUS_SUMMARY`, артефакт `reports/real-corpus-E0.json` доступен в запуске Actions, но **не коммитится как авторитетный набор текстов**.

**Не путать:** это реально исполняемая структурная компиляция целых книг и статей, НЕ семантический анализ русского языка, не извлечение требований и не native FORMAL/Γ/AGI. Ни MDL-оптимум, ни коэффициент сжатия реального файла пока не доказаны. Gzip baseline служит контрольным сравнением; большой JSON с SHA256 вполне может быть намного больше исходного текста.

MDN: Mozilla Contributors, prose CC BY-SA 2.5+, кодовые примеры могут иметь отдельное лицензирование; исходные файлы не изменяются. Gutenberg ebook #11 — Public Domain в США, иные юрисдикции требуют самостоятельной проверки. RusLit README заявляет public domain, отбор произведений старых авторов. Это указание происхождения и условий использования, а не универсальное юридическое заключение.

**Отрицательные критерии:** любая потеря байтов, изменение source blob SHA, утечка holdout, несовпадение восстановленных Counter caches, ложный semantic success, silent resource exhaustion → FAIL. Ограничение 350000 Unicode codepoints на отдельный файл, все файлы обязаны пройти; обрыв измерений не считается успехом.

Эта работа отдельным PR поверх принятого P0; экспериментальные Γ-ветки не затрагивает и не сливает.
