# E6 — книги и статьи, настоящий посимвольный вход и пересмотр старых Links

Исследование #42, не новая семантика МТС v0.15. Проверяются три полных произведения (книга Кэрролла, публицистика Толстого и документация MDN) из оригинального corpus/real-sources-e0.json. Загружаются по неизменяемым SHA upstream Git коммитов. Размер, Git blob SHA-1 и полный восстановленный UTF-8 байтовый поток проверяются. Самих чужих текстов в отчёте/репозитории нет.

Протокол: initial bootstrap 384 Unicode codepoints, три старые watch views по 64 codepoints, затем каждый поступающий codepoint передаётся как один уникальный внешний event. E5 обновляет ровно один новый соседний pair в indexed heap, при смене selected rule создаёт только реально затронутые задачи. Каждые 8192 символа лидер перепроверяется независимым full-scan oracle. Если натуральный текст не вызывает поздней перестройки, это **отрицательный результат**, а не ошибка теста.

**Главная метрика** — количество уникальных достижимых Link-дуплетов. По окончании потока специально, *отдельным полным batch-проходом*, строится полный исходный root, а далее считаются selected Link-pairs исходного root, текущих watched views и выбранного правила. Второй показатель включает также ранний source root и все исторические watched roots/rules. Это ещё не полная FORMAL/Γ memory/network с contexts/provenance, а именно структурный source-graph scope. Декодирование последнего полного root строго восстанавливает исходные UTF-8 байты.

Первая фаза bootstrap требует O(n) прохода; на append **одно** новое соседство, хотя при смене правила старые фрагменты нуждаются в повторном вычислении. Тест честно считает их codepoints и отдельно затраты построения полного source root. Исходный full root пока не обновляется инкрементально. Нет доказательства глобального минимума, вероятностных весов, native Γ, AGI или исправления ошибок текста. PR не сливать до принятия полной последовательности и governance-grant #35.
