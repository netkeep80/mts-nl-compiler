# W19 B0 — исходная Unicode-статистика против Link-контекстов (исследовательский нулевой тест)

Связанные issues: [#1](https://github.com/netkeep80/mts-nl-compiler/issues/1) / [#13](https://github.com/netkeep80/mts-nl-compiler/issues/13) / [#17](https://github.com/netkeep80/mts-nl-compiler/issues/17) / [#91](https://github.com/netkeep80/mts-nl-compiler/issues/91).

**Статус:** experimental B0 baseline; не нормативная компиляция, не доказательство семантики, не обученная МТС Γ, не изменение `weight`. Принятый `main` и SQLite сохраняются.

## Научный вопрос и нулевая гипотеза

Даёт ли простое хранение *одних и тех же* наблюдаемых контекстов в виде бинарных Link новую предсказательную информацию по сравнению с обычной таблицей Unicode n-грамм? Нулевая гипотеза: **нет**. Для равных независимых частот исходных скаляров `raw`, `link-left`, `link-balanced` обязаны возвращать одни и те же распределения. Это защита от иллюзии, что бинаризация сама по себе дала «понимание».

`src/w19-capability-b0.mjs` считает **каждую исходную Unicode-позицию ровно одним наблюдением** в отдельном документе. Для длин контекста 0..3 из тех же наблюдений считает отдельные гистограммы следующего скаляра (не берёт `from_uses`, `to_uses`, Link reuse или автоматически выведенные тексты). Экспериментальная Link-версия использует обычные интернированные `(from,to)` для хранения *ключа контекста*, с двумя альтернативными бинаризациями; не выдаёт ordinal ID за SQLite identity. `ContextLinkGraph.decode(encode(context)) == context`, никакого `split(' ')`, словаря, POS, языка, утверждений о морфемах.

Вероятность задаётся **только** на алфавите Unicode-скаляров, виденном в `train`:

`P(c | x) = (observed(x,c) + alpha) / (observed(x) + alpha * |V_train|)`, `alpha=0.5`.

Суффиксный backoff `x` от 3 до 0, если контекст не наблюдался. Все `|V_train|` альтернативы нормированы к 1; значения не записываются в МТС `weight`. Для тестового скаляра **вне** `V_train` нет заявленной индивидуальной `P(c)`: фиксируется `ABSTAIN/OOV`, а не выдуманная вероятность. `bitsPerScoredScalar` и accuracy вычисляются **только на покрытых событиях**, coverage публикуется отдельно; не следует интерпретировать их как безусловную perplexity всего текста.

## Данные, без утечки holdout

Синтетический редакционный fixture `tests/fixtures/w19-capability-pairs-v0.json` содержит 10 train-фраз, 4 отдельные heldout-фразы и 6 контролируемых пар: орфографический пропуск, грамматический контраст, два корректных модальных варианта, неверное обращение импликации, редкую корректную формулировку, математическую альтернативу. **Метки пока не являются независимым human-reviewed gold**. Некоторые альтернативы законны, некоторые вовсе не сравнимы по словарю train: `ABSTAIN_OOV` — допустимый результат.

`comparePairs` даёт только разницу средней surprise в битах на покрытый скаляр или `ABSTAIN_OOV`. Он **не** возвращает `isError` и не исправляет требования. Даже если грамматически правильная редкая фраза получила более высокую surprisal, это **не** false semantic verdict, пока система вообще не делает semantic verdict.

## Независимые автоматические проверки

- Raw n-gram и две формы Link обязаны иметь равные `heldout` оценки, backoff и все индивидуальные paired-report; это контроль нулевой гипотезы, не доказательство преимущества
- Перестановка структуры `left/balanced` не меняет значение контекста и вероятности
- Новые тестовые контексты **не создают новых Links**: `encode(...,{create:false})`; оценка не меняет статистику/снимок
- `train` и `heldout` не объединяются; exact SHA обучающих документов и fixtures публикуется
- Unicode: кириллица, emoji, combining mark, CRLF, NUL, математические знаки, корректное отклонение непарных UTF-16 суррогатов
- Отрицательные случаи: OOV, неверный бюджет порядка/параметров вероятностей, невозможность утверждать логическую истинность
- Детерминированный процесс генерирует один JSON без времени, случайности, скачивания текстов и изменений `main`

Воспроизведение на Node >=24:

```bash
node --test tests/w19-capability-b0.test.mjs
node scripts/w19_capability_b0.mjs > w19-b0-report.json
```

Все файлы fixture полностью синтетические и не включают внешние книги. Классы phrase/logic строго исследовательские; результирующее свидетельство является **контролем корректности предиктивного baseline**, а не шагом к AGI.

## Следующий эксперимент после B0

Проверить на matched-budget обучении продуктивные переносимые классы `root×affix`, unseen combinations и paired-world n-gram surrogates с независимым gold (issues #79/#85), а затем минимальные грамматические/логические контрасты #91; каждый результат сравнивать со статистической нулевой гипотезой и фиксировать случаи ухудшения/UNKNOWN. Отдельно требуется представление произвольной МТС-асети: W15F1/W17 сериализует только ациклический последовательностный граф и не кодирует общие веса/роли/циклы/правила.
