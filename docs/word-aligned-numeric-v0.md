# Word-aligned numeric physical Links — эксперимент #68

Экспериментальный компилятор целых слов и фрагментов фраз без каких-либо SHA-идентификаторов Link. Принятый канонический E0 и научные E1–E7 пока не заменяются этим прототипом.

Каждая входная книга декодируется строгим UTF-8, без нормализации Unicode, сохранение U+FEFF, CRLF, пробелов и пунктуации — обязательно. Исходный поток разделяется на чередующиеся **точные** непрерывные сегменты «буквы/сочетательные знаки/цифры» и «всё остальное». Инициируются обычные SQLite Link: сначала сбалансированная двоичная структура символов каждого слова, затем отдельные сепараторы. Сегмент слова с последующим разделителем объединяется в единицу word+separator. Полученные единицы формируют сбалансированное дерево по **границам слов**, поэтому физически существуют reachable Link для целых слов и ряда многословных последовательностей (например, «мама мыла »), чего нет гарантированно у посимвольного balanced baseline.

Свойство «существует Link для слова/фразы» нужно проверять по **достижимости от опубликованного root**, а не по подставленной аналитической словарной таблице. Явная политика повторного использования по точному равенству числовых полюсов: никаких хешей пары, \`UNIQUE(from_id,to_id)\` или автоматического отождествления всех Link. Совпадение слов не гарантирует принудительное объединение в один Link.

Точность: результат компиляции обязан побайтово восстановить входной UTF-8. Консистентность при SQL-ошибках требует атомарный COMMIT/ROLLBACK. Экспериментальный E0 не меняет принятую семантику MTS v0.15, значение \`weight\`, production Γ или контракт версионированного архива.

**Пределы:** дерево word-aligned лишь делает словесные границы явными; оно ещё не реализует статистически оптимальное разбиение на часто повторяющиеся многословные фразы. Вложенные сегменты могут пересекать конец предложения, включать пунктуацию. Реальный A/B 60 произведений должен сравнить selected Link coverage, стоимость загрузки, количество Link, SQLite bytes, cold exact replay, а затем открыть отдельную оптимизацию по статистически выбранным фразам. Не путать частоты исходных токенов, selected Link events и выбор правила обучения.

Тесты сравнивают word-aligned и balanced char для одинакового Unicode, наличие достижимых полных слов и двухсловных Link, replay, неуникальность равнополюсных связей и SQL rollback.
