# #22 — Экспорт асети в JSON с деревьями последовательностей

**Экспериментальная форма**. Допустимые JSON values: `string`, `object`, `null` **исключительно в конце sequence tree** (`$next:null` или `$tree:null` для пустой последовательности). **Без JSON numbers, arrays, booleans**.

## Пример

[Демонстрация «мама»](fixtures/mama-object-tree.json): одна асеть, включающая `ma=(м,а)`, `mama=(ma,ma)` с повторным использованием *того же самого* `ma`, плюс явный ordered sequence carrier `s:1…s:4`.

Canonical `$links` — объект определений всех уникальных Links по **собственным ID**. Атом: `{"string":"м"}` (from/to отсутствуют). Дуплет: `{"from":"m","to":"a"}`; `string` у дуплета необязательна. `weight` при наличии — **строковое** представление исходного finite IEEE754 числа `0…1`, например `"0.75"`; отсутствие `weight` означает исходное SQL `NULL`. Прямое JSON `null` для неизвестного веса **запрещено**.

`$sequences` задаёт **производные** вложенные объектные деревья выбранных конс-последовательностей; `$item:{"$ref":"ID"}`, `$next:{...}`, конец `$next:null`; `$root` и `$terminator` — строковые IDs исходных Links. Повторно встреченная хвостовая ветка может выглядеть `{"$ref":"ID"}`; она всё равно определяется в `$links`. Без этого произвольный DAG и циклы невозможно представить конечным чистым деревом с сохранением идентичности. `$links` владеет точным графом; derived view при импорте **воссоздаётся из него и сравнивается**, вместо самостоятельного определения фактов.

Человекочитаемое `{"м":{"а":{"м":{"а":null}}}}` — **не канонический экспорт асети**: оно теряет тождества и различия совпадающе подписанных Link IDs, весов и ссылок. Оно допустимо только как необязательное представление простой строки, если позднее понадобится.

## Границы и проверки

- Импорт принимает **исходные JSON-байты как UTF-8 текст**, не уже разобранный объект; иначе нельзя обнаружить повторные имена в `{}` до JSON.parse. Неполные, неизвестные, одинарные endpoints, неверные weights и циклические *выбранные последовательности* отклоняются.
- Непомеченные циклические асети, структурные отношения, правила вывода и параллельные Links сохраняются через `$links`, даже если дерево последовательности для них не выбрано.
- Unicode не нормализуется; отдельная проверка отсекает некорректные одиночные UTF-16 surrogates. Тесты включают смешанные алфавиты, math symbols, пробелы и повторения.
- `from_uses/to_uses` не сериализуются как authority: пересчитываются из графовых полюсов после импорта; исходные данные остаются в одной SQLite subject table.
- Список выбранных последовательностей — **точный параметр экспорта**: неопределённый тип роли Links нельзя угадывать из наличия двух полюсов. Произвольный Link `(A,B)` сам по себе не последовательность, а тем более не логическая импликация.
- Это ещё не точная FORMAL v0.15 JSON-проекция; требуется независимый roundtrip/metacompiler/Γ replay перед признанием совместимости.
- Целевой формат удобен для просмотра и interchange, но не считается оптимальным сжатием по MDL. Сравнивать его byte cost с бинарными и плоскими альтернативами.
