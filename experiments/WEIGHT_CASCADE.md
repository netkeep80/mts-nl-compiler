# #30. Непрерывный каскад Γ и разделение источников оценок

**Исследовательский эксперимент**, не принятое определение вероятности и не изменение МТС v0.15.

## Доказанное исполнением

- Настоящая тестовая Γ A9 из anum_docs при точном SHA c64b7e21340c6add248c8f380f3fef1292616ac6, без изменения её реализации.
- Только после внешнего события t4 активируется контекст. Три поколения Γ дают arrival → raw(мама) → compressed((ма)(ма)) → recognized. Четвёртое поколение QUIESCENT.
- Исходный ранее наблюдённый префикс «мам» и полная последовательность «мама» сохраняются. Предложенное переписывание даёт те же декодируемые символы.
- Числовое поле weight=0 и weight=1 у связевого правила даёт одинаковую логическую трассу: незаявленная весовая семантика не проникает в Γ.
- Циклическая пара переинтерпретаций не приводит к QUIESCENT. Внешний тестовый планировщик прекращает исполнение после восьми поколений с RESOURCE_LIMIT. Это **не** автоматическое обнаружение циклов в исходной Γ.

## Независимая проверка обучения

Экспериментальный восстанавливаемый оракул в experiments/evidence-score-oracle-v0.mjs различает два типа событий: external observation и generated proof. По ID внешнего наблюдения выполняется дедупликация и отказ при противоречивом повторном использовании ID.

Для сравнения режимов задан пробный score = n/(n+1) с n — числом независимых внешних наблюдений выбранной пары (контекст, значение). Это **не вероятность**, не формула МТС и не часть native Γ. При одном наблюдении score=0.5. После 10 000 внутренних порождений он остаётся 0.5. После второго независимого наблюдения score=2/3. Нельзя выводить из этого калибровку условной вероятности.

## Открытые условия

- Пока не задана автором семантика weight; выбранное весовое свидетельство как Link-посылка не компилируется в единую принятую семантическую теорию.
- Физические from_uses/to_uses при переписывании могут изменяться, но это структурные кэши, не статистика независимых наблюдений.
- Нет полного графового native semantic parity для параллельных полюсов и произвольных циклов; перенос происходит через явный регистр и ограниченную проекцию.
- Нет production Gamma API и автоматически доказанной устойчивости/сходимости каскадов.
- Нет реальной долговременной экономии с сохранением полного provenance: см. #20.

Не merge до отдельной авторской проверки exact SHA.
